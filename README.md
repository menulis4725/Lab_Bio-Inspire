# Lab Bio-Inspire — แหล่งส่งงานเดิม

## สำหรับตรวจประวัติและเวลาส่งงาน

โปรดตรวจประวัติ commit และการเปลี่ยนแปลงไฟล์ใน repository นี้เป็นหลัก:
- [ประวัติ commit ของงานเดิม](https://github.com/menulis4725/Lab_Bio-Inspire/commits/main/)
- [งานเดิมก่อนเพิ่มคำอธิบายการย้าย](https://github.com/menulis4725/Lab_Bio-Inspire/tree/20e40081f249d924f68974effd64330d507a9c12)

วันที่ commit ที่คัดลอกงานเข้า repository ใหม่เป็นวันที่ย้ายสำเนา ไม่ใช่วันที่ส่งงานครั้งแรก การตรวจเวลาส่งให้พิจารณา commit ของไฟล์/แลปที่เกี่ยวข้องใน repository เดิม ไม่ใช้วันที่แก้ README นี้แทน
